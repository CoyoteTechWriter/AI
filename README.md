
## Purpose

This code is a simple stateless CNN neural network that learns to differentiate between images of cats and dogs from the dataset.

This network does not have memory, so it does not remember what it learned. The reason for this is to watch the process of learning and manipulating epochs to see how to avoid overfitting.

## Usage

1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/yourusername/your_project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd your_project
   ```

3. Run the main script:

   ```bash
   python main.py
   ```

This will load the dataset from the specified relative path and display the first few rows in the console.

## Dataset

The dataset used in this project is a kaggle dataset which you can find here -> https://www.kaggle.com/datasets/shaunthesheep/microsoft-catsvsdogs-dataset
